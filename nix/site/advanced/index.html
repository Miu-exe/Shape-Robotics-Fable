How to use this reference
  • Pick Settings (gear) → Toolbox → Advanced to show these blocks; the categories are down the left of the workspace.
  • On Module dropdown: blocks for a Joint, Spin or Face act on one module. Connect the hub first, then pick the module's ID (for example LJ9). Left on “none”, the block does nothing.
  • Order: blocks run top to bottom, each waiting for the one before. Spin Set Drive … and Spin Set Spin … keep moving while the next blocks run; the program waits for them before it ends.
  • Speed is a percentage of the motor's top speed: Spin −100 to 100 (negative = reverse), Joint 0 to 100. Values outside the range are capped and listed under the “!” warnings.
  • Camera blocks (Vision) use the camera of the device you program on; AI Senses use the Face module's camera.
  • Every block also exists as text code: View code shows it, and Text mode accepts the same commands.
