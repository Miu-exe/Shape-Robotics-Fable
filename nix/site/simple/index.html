How to use this reference
  • Pick Settings (gear) → Toolbox → Simple to show these blocks; the categories are down the left of the workspace.
  • On Module dropdown: blocks for a Joint, Spin or Face act on one module. Connect the hub first, then pick the module's ID (for example LJ9). Left on “none”, the block does nothing.
  • Order: blocks run top to bottom, each waiting for the one before. Spin Set Drive and Spin Set Spin keep moving while the next blocks run; the program waits for them before it ends.
  • Speed is a percentage (0–100) of the motor's top speed.
  • Numbers go in the round slots: drag a Math block in, or type over the number already there.

Logic

Decisions: run blocks only when something is true.

if … do

Runs the blocks inside only when the condition is true.

Settings Condition slot (a Logic or Input block).

if … do … else

Runs the first group when the condition is true, otherwise the second.

Settings Condition slot.

True when the two values compare as chosen.

and: true when both sides are true. or: true when at least one is.

Settings and, or

not [ ]

Turns true into false and false into true.

Output

Make things happen: drive a Spin, move a Joint, change the Face, light up modules, speak and play sounds.

Spin Set Drive Forward

Starts the Spin driving (speed 50) and keeps going until another drive block, Stop, or the end of the program. Left / Right turn on the spot.

Settings Forward, Backward, Stop, Left, Right · module

Spin Set Drive [75] Centimeters

Drives straight that distance at speed 50, then stops. A negative number drives backward.

Settings Distance · Meters, Centimeters, Feet, Inches · module

Spin Set Spin [90] Degrees

Turns on the spot by that amount at speed 50. Positive turns clockwise (12 → 3 o'clock), negative counterclockwise.

Settings Amount · Times (full turns), Degrees, Radians · module

Spin Set Headlights

Switches the Spin's headlights.

Settings Turn On, Turn Off, Toggle · module

Joint Set Motor Position x: y:

Moves the Joint's two motors to these angles (speed 50).

Settings x and y: −90 to 90 degrees · module

Face Set Emotion

Shows an expression on the Face.

Settings Neutral, Happy, Sad, Angry, Tired, Surprised, Fear, Disgust, Close Left Eye, Close Right Eye

Face Set Eyes Color

Colors the Face's irises or eyelids.

Settings Iris, Eyelid · color slot

Set Color

Sets the light of a module (or the hub) to a color.

Settings Color slot · module

Speak

Says the text out loud.

Settings Text slot · English, Română, Polski, Українська, العربية, Dansk, Français, Español, Nederlands, Italiano, Deutsch, Русский

Play Sound

Plays a sound effect.

Settings Angry, Boing, Buzz, Chimp, Elephant, Drum, Fart 1, Fart 2, Laugh, Pling, Running, The End, Twirly, Woof

Play Note

Settings C, D, E, F, G, A, B, C High

Loops

Repeat blocks, or wait.

Wait Time [1]

Pauses the program for that many seconds.

Settings Seconds (decimals allowed).

Wait Until [ ]

Pauses until the condition becomes true. Comes with Spin Has Reached Target in the slot.

Settings Condition slot.

repeat while [ ] do

while: repeats the blocks inside as long as the condition is true. until: repeats until it becomes true.

Settings while, until · condition slot

repeat [10] times do

Repeats the blocks inside a set number of times.

Settings Number of times.

While Forever do

Repeats the blocks inside until you press Stop.

Settings —

break out of loop

Inside a loop: break out leaves the loop now; continue with next iteration skips to the next round.

Settings break out, continue with next iteration

Input

Read sensors, motors, time and keys. These blocks fit into slots (for example in if or Wait Until).

True when any of the Spin's three distance sensors reaches that level, i.e. something is close to it.

Settings Level 0–100 (higher = nearer) · module

True when the chosen color sensor sees that color (the headlight turns on to look).

Settings red, green, blue, yellow, magenta, cyan, white, black · sensor 1, 2, 3 · module

True when the last Spin Set Drive … cm or Spin Set Spin has finished.

Settings No Motors, Any Motors, Both Motors, Motor A, Motor B · module
